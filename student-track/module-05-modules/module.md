# Module 05 — Conception de Modules Réutilisables

**Durée :** 2 heures  
**Prérequis :** Module 04 validé  
**Mission :** Extraire une architecture monolithique en un module enfant réutilisable (Pattern Landing Zone) avec un contrat d'interface strict (inputs/outputs).

## Démarrer

### Windows (PowerShell)

```powershell
.\scripts\New-StudentWorkspace.ps1 -Module 5 -Initials ABC
code "$HOME\Data2AI-Labs\module-05-modules"
```

### Linux/macOS (Bash)

```bash
bash ./scripts/new-student-workspace.sh --module 5 --initials ABC
code "$HOME/Data2AI-Labs/module-05-modules"
```
