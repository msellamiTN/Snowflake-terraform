# Module 11 — RBAC as Code & Sécurité au Moindre Privilège

**Durée :** 2h15  
**Prérequis :** Module 10 validé  
**Mission :** Construire une matrice de contrôle d'accès Snowflake (RBAC) complète et automatisée avec Terraform : rôles fonctionnels (`FR_*`), rôles d'accès (`AR_*`), Future Grants sur objets à venir et tests de non-régression de permissions.

## Démarrer

### Windows (PowerShell)

```powershell
.\scripts\New-StudentWorkspace.ps1 -Module 11 -Initials ABC
code "$HOME\Data2AI-Labs\module-11-rbac"
```

### Linux/macOS (Bash)

```bash
bash ./scripts/new-student-workspace.sh --module 11 --initials ABC
code "$HOME/Data2AI-Labs/module-11-rbac"
```
