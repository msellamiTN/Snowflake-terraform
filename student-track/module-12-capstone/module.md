# Module 12 — Projet Fil Rouge (Enterprise Capstone Challenge)

**Durée :** 2h15  
**Prérequis :** Modules 01 à 11 validés  
**Mission :** Assembler et déployer de bout en bout une plateforme de données gouvernée, industrielle et sécurisée sur Snowflake et Azure, intégrant l'état distant sur Azure Blob, les secrets dans Azure Key Vault, les modules de Landing Zone, la matrice RBAC, les monitors de coûts et un pipeline Azure DevOps.

## Démarrer

### Windows (PowerShell)

```powershell
.\scripts\New-StudentWorkspace.ps1 -Module 12 -Initials ABC
code "$HOME\Data2AI-Labs\module-12-capstone"
```

### Linux/macOS (Bash)

```bash
bash ./scripts/new-student-workspace.sh --module 12 --initials ABC
code "$HOME/Data2AI-Labs/module-12-capstone"
```
