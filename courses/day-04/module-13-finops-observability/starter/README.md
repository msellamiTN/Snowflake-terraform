# Starter M13

Le code de départ est le projet exécutable `finops/`.

1. Copiez `finops/profiles.yml.example` vers `~/.dbt/profiles.yml`.
2. Remplacez les placeholders hors Git.
3. Exécutez `dbt deps`, `dbt debug`, puis `dbt build`.
4. Complétez l'analyse en produisant une recommandation issue d'un mart.

Ne copiez ni mot de passe ni clé privée dans ce dossier.
