# Code de départ — M0 : Préparation de l'environnement

Ce module ne contient pas de code Terraform. C'est un lab de configuration uniquement.

## Ce qu'il faut préparer

Aucun fichier à copier. Les participants configurent leur environnement :

1. Installer Terraform 1.14.5
2. Installer Snow CLI (`pip install snowflake-cli-latest`)
3. Installer Azure CLI 2.83.0+
4. Configurer la connexion Snowflake (JWT ou fallback mot de passe)
5. Enregistrer le code d'équipe

## Référence source

Aucune racine `project/` ne correspond à M0. Les instructions de configuration sont dans `lab.md`.
